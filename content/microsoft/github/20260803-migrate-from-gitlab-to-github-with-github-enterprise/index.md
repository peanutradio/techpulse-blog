title: Migrate from GitLab to GitHub with GitHub Enterprise Importer
---

Migrations from gitlab.com and GitLab Self-Managed to GitHub Enterprise Cloud with GitHub Enterprise Importer (GEI) are now generally available. You can now self-serve these migrations using GEI and the gh gl2gh command-line extension.

With this release, you can now:

Migrate repositories from gitlab.com and currently maintained versions of GitLab Self-Managed.
Run single-repository migrations or scripted bulk migrations with the gh gl2gh extension.
Stage migration archives in GitHub-owned blob storage (--use-github-storage) or your own AWS S3 or Azure Blob storage account.

This capability supports migrations into organizations on GitHub Enterprise Cloud on github.com and ghe.com. Migrations from GitLab to GitHub Enterprise Server are not supported.
To start migrating your GitLab repositories, check out our documentation on migrating from GitLab to GitHub, and if you&rsquo;d like help planning your migration, contact our Expert Services team.
