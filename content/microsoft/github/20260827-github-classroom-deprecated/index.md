title: GitHub Classroom deprecated

As of August 28, 2026, GitHub Classroom is now deprecated in favor of our selected partner solutions. The GitHub Classroom website, APIs, and related services have now been decommissioned. However, any GitHub user accounts, repositories, and organizations created to work with Classroom are not affected. Some GitHub Classroom data (e.g., classroom and assignment names, tests defined outside of repositories, and LTI integrated rosters) will be permanently deleted in accordance with GitHub&rsquo;s data retention policies.
This completes the transition process we announced on May 26.
For more information about this transition and recommended partner solutions, please refer to the GitHub Educator Community Discussion.
