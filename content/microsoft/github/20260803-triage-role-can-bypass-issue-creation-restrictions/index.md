title: Triage role can bypass issue creation restrictions
---

If your repository restricts issue creation to collaborators only, users with the triage role can now create issues.
Previously, the restricted setting only allowed users with write access to create issues. With this update, trusted contributors with the triage role are also included. This helps teams keep issue creation restricted while still enabling triage-role users to more effectively support intake and repository maintenance.
