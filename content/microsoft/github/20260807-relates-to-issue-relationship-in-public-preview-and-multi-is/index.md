GitHub is making it easier to connect related work and manage multiple field values across issues and projects.
Connect related issues


The new &ldquo;Relates to&rdquo; issue relationship is available in public preview. You can connect two issues without implying that one blocks, duplicates, contains, or closes the other.
Multi-select fields are generally available
Multi-select fields in issues and projects are now generally available, with several improvements:

Slice and group project items by multi-select fields in table and board views.
View and edit multi-select values from issue and pull request sidebars.
Copy and paste multi-select values in the table view.
Clear multi-select values from project items.

Join the discussion within GitHub Community.
