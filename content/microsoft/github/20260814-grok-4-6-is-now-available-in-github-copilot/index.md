Grok 4.6, xAI&rsquo;s latest reasoning model, is now rolling out in GitHub Copilot. It is designed for agentic coding and complex multi-step workflows.
In our internal testing, Grok 4.6 showed strong results across terminal-based coding tasks in Visual Studio Code and Copilot CLI. It performed especially well on longer-horizon tasks requiring sustained reasoning and tool use, making it a strong fit for complex coding workflows.
This model is billed at provider list pricing under usage-based billing. See GitHub Copilot&rsquo;s pricing for models and requests for details.
Availability in GitHub Copilot
Grok 4.6 will be available to Copilot Pro, Pro+, Max, Business, and Enterprise SKUs.
You&rsquo;ll be able to select the model in the model picker in:

Visual Studio Code
Visual Studio
Copilot CLI
GitHub Copilot cloud agent
GitHub Copilot app
JetBrains
Xcode
Eclipse

Rollout will be gradual. Check back soon if you don&rsquo;t see it yet.
Enabling access
Copilot Enterprise and Copilot Business plan administrators must enable the Grok 4.6 policy in Copilot settings. The policy is off by default.

To explore all models available in GitHub Copilot, see our documentation on models and get started with Copilot.
