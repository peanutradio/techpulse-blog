We have updated how model access is determined for Copilot users who hold seats in more than one organization. To keep billing and governance in sync, your model access is now determined only by the organization paying for your usage.
What&rsquo;s changing
Before this change, if you had Copilot seats in more than one organization, you could use a model as long as any of your organizations enabled it. With this update, your billing organization decides model access. You can find this organization under &ldquo;Usage billed to&rdquo; in the Copilot features page. For more information about how policies apply, read the GitHub Copilot policy documentation.
What isn&rsquo;t changing
If your Copilot access comes entirely through an enterprise or its organizations, your model access will not be impacted by this update.
