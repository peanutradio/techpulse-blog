July 2026 brought a new agent based on the Copilot SDK, built-in expertise from the .NET and Azure teams, and more ways to tailor GitHub Copilot to how you and your team work.
Highlights
Here&rsquo;s what&rsquo;s new with GitHub Copilot in Visual Studio 2026. Check the Insiders channel for the latest:

Try the new agent, now in public preview: Copilot Chat has a new Agent (Preview) option in the agent picker, built on the same GitHub Copilot SDK that powers the GitHub Copilot CLI. It gets more tasks right the first time with less back-and-forth. Responses are shorter and easier to scan. Select it from the agent picker at the bottom of the Copilot Chat window.
Built-in .NET and Azure skills: Visual Studio now includes built-in skills authored by experts from the .NET and Azure teams to help you customize your agentic workflow. Find them in the &ldquo;Built-in&rdquo; category of the tool picker when the corresponding workloads are installed. They&rsquo;re off by default, so you can review and enable only the ones that fit your tasks.
Review selected code with Copilot: Sometimes you just want a second opinion on a specific block of code. Select code in the editor, right-click, and select Copilot Actions &gt; Review Selection to get inline comments you can act on. Use the sparkle icon on any comment to apply a suggestion or have Copilot generate one, powered by GitHub Copilot code review.
Organization-level custom instructions: GitHub organization owners can now add custom instructions that tailor Copilot&rsquo;s responses across the entire organization, so shared preferences don&rsquo;t have to be configured per developer. They automatically apply in repositories that belong to your organization and appear in the reference list, and you can disable them under Tools &gt; Options &gt; GitHub &gt; Copilot &gt; Copilot Chat.

Availability varies by feature. Organization-level custom instructions require GitHub Copilot Business or GitHub Copilot Enterprise. The new agent, built-in skills, and selected-code review features are available in all plans. See GitHub Copilot plans for details.
To learn more about what&rsquo;s new, check out the Visual Studio blog and release notes.
What&rsquo;s next for Copilot in Visual Studio
Stay up to date on the latest Copilot features by following the Visual Studio blog, where you&rsquo;ll find roadmap updates and opportunities to share feedback.
