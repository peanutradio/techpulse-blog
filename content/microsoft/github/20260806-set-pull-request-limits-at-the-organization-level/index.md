title: Set pull request limits at the organization level
---

You can now set pull request limits at the organization level. Pull request limits let you define how many open pull requests a user without write access can have at one time. If a user reaches that limit, they must close or merge an existing pull request before opening another.
With this update, you can manage pull request limits centrally across all repositories in your organization instead of configuring them one repository at a time. This helps you apply a consistent policy at scale and reduces administrative overhead for maintainers managing many repositories.
To set pull request limits for your organization:

Navigate to your organization&rsquo;s settings.
In the left side bar go to Moderation tools &ndash;&gt; Interaction limits.
At the bottom of the page, set your pull request limits.
