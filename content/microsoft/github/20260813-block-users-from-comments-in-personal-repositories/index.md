title: Block users from comments in personal repositories
---

You can now block or unblock users directly from comments on pull requests and issues in repositories owned by personal GitHub accounts.
To block or unblock a user:

Open the More menu on their comment.
Select Block user or Unblock user.
Optionally add a private note explaining why you&rsquo;re blocking the user.
Confirm your selection.

This shortcut makes it faster for maintainers to manage spam and unwanted activity without leaving the pull request or issue.
If you have any questions or feedback, leave a comment in our Community discussion.
