We&rsquo;re making it easier to keep labels organized and find the right one, especially in repositories with long and growing label lists.
Suggested Labels

You can now find the right label faster with suggestions based on what a repository has been using recently. You can also see Recent labels based on your own usage, making it easier to label issues without searching through the full list.
Archive Labels


You can now archive labels you no longer use without losing their history on existing issues. This keeps the label picker focused on active labels, making it faster and easier to find the right one. You can unarchive a label at any time from the repository Labels page.
