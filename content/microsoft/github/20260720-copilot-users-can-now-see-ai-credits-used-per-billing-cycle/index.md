title: Copilot users can now see AI credits used per billing cycle
---

Copilot Business and Copilot Enterprise users can now see how many AI credits they&rsquo;ve used this billing cycle, even without an individual budget. Find this on your GitHub Copilot usage page in your GitHub settings.
Previously, the page showed usage only as a percentage of a budget. Many users don&rsquo;t have an individual budget, so that percentage gave them no view of their monthly usage and no way to contextualize their token usage.
Now the page reflects your actual usage:

If your account admin hasn&rsquo;t set a budget, you see the total AI credits you&rsquo;ve used this cycle.
If your admin sets a budget, you see the credits you&rsquo;ve used out of your total budgeted amount.

To learn more, see Budgets for usage-based billing.
