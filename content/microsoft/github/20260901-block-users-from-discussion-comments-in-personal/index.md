title: Block users from discussion comments in personal repositories
---

You can now block or unblock users directly from discussion comments in repositories owned by personal GitHub accounts, extending the in-context blocking controls already available for issue and pull request comments.
To block or unblock a user from a discussion comment:

Open the More menu on their comment.
Select Block user or Unblock user.
Optionally add a private note explaining why you&rsquo;re blocking the user.
Confirm your selection.

If you have any questions or feedback, join the discussion in our community discussion.
