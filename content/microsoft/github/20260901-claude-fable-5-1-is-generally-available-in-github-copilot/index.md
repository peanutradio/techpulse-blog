Claude Fable 5.1 from Anthropic is now available in GitHub Copilot. The latest model in Anthropic&rsquo;s Mythos class, Claude Fable 5.1 is designed for long-horizon, autonomous coding and knowledge-work tasks.
In our internal testing, Claude Fable 5.1 demonstrated strong performance on substantial, long-running coding tasks, including deep codebase research, feature development, and complex agentic workflows.
Unlike other Claude models in GitHub Copilot, Claude Fable 5.1 requires data retention by default to operate Anthropic&rsquo;s safety classifiers. Zero data retention access is available for certain eligible enterprise customers. Continue reading for more details.
This model is billed at provider list pricing under usage-based billing. See pricing for GitHub Copilot models and requests for details.

Rollout will be gradual. Check back soon if you don&rsquo;t see it yet.
Enabling access
Copilot Enterprise and Copilot Business plan administrators must enable the Claude Fable 5.1 policy in Copilot settings. The policy is off by default.
Claude Fable 5.1 requires data retention by default. When Claude Fable 5.1 is used, Anthropic retains data, including prompts and outputs, to operate safety classifiers that detect harmful use. Retained data is not used to train Anthropic&rsquo;s models. Other Claude models, except for Fable 5 and Fable 5.1, continue to operate under zero Data Retention (ZDR).
To learn more, see Anthropic&rsquo;s data retention practices for Mythos-class models. Enabling the Claude Fable 5.1 policy constitutes acknowledgment of this requirement. Leaving it off keeps Claude Fable 5.1 unavailable to your organization.
Zero data retention access for eligible enterprises
Eligible customers can use Claude Fable 5.1 as well as Claude Fable 5 with zero data retention through the end of the calendar year under a time-bound exemption while Anthropic rolls out Enterprise Frontier Safeguards (EFS). After that point, continued use of the models will require EFS, which will enable automated safety monitoring while also giving eligible customers more options for how their data is retained. This includes the option to use storage and encryption keys under their own control. Between now and then we will be working with Anthropic to provide feedback on EFS.
If your enterprise is approved for access, Claude Fable 5.1 and Fable 5 requests will be routed to zero data retention endpoints when the model is enabled. To learn whether your organization qualifies, contact your GitHub account team. GitHub Support cannot determine eligibility or enable access.
Approval will not automatically enable the models. After approval, a Copilot Enterprise or Copilot Business administrator must still enable Claude Fable 5.1 and Claude Fable 5 policy in Copilot settings.
