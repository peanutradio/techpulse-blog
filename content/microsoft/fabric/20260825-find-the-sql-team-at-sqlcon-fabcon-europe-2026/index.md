Twenty sessions. Four days. One short link!
The Microsoft SQL product team is heading to Barcelona for SQLCon Europe 2026, September 28 to October 1, co-located with FabCon Europe. The people building SQL Server, Azure SQL, and SQL database in Fabric are presenting what's new and the roadmap, and then sticking around to answer your questions and discuss your ideas and problems-to-solve.
Bookmark this or remember to URL to find it later: aka.ms/sqlsessions
By the way, if you haven't registered yet and have decided you want to come, you can register online now!

Where to start
Start with the corenote on Tuesday at 11:15. Priya Sathy, VP of Microsoft SQL, will join Bob and me to cover where SQL is going across SQL Server, Azure SQL, and Fabric SQL. Everything else on this schedule goes deeper.
Between sessions
Come find us at the Microsoft booth and in the Community zone. Bring the migration you’re stuck on, the query that won’t go faster, or the feature request you’ve been sitting on. The booth conversations are always the highlight of the trip for me, so please stop by.
Room assignments are not published yet. The venue signage maps sessions with session IDs like T03 and W54, so note the ID rather than a room number, and check aka.ms/sqlsessions onsite.
