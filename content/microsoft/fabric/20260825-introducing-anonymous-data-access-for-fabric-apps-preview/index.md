title: Introducing anonymous data access for Fabric Apps (Preview)
---

Fabric Apps now support&nbsp;anonymous data access&nbsp;to enable public-facing experiences without mandatory sign-in. This feature balances accessibility with security by exposing only specific data and operations to unauthenticated users under strict administrative controls.

Access requires tenant admin approval, explicit app opt-in, and data-model role permissions for anonymous users.
Developers can grant read or create permissions for public data like catalogs or event registrations while protecting sensitive information.
Best practices include minimal permission grants, field restrictions, input validation, and monitoring to safeguard data integrity.
