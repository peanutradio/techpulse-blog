Microsoft Fabric &amp; Microsoft SQL Community Conference, the premier gathering for data professionals, developers, and business leaders who are shaping the future of data and analytics, is happening in Atlanta, GA, from March 8-12, 2027, at the Georgia World Congress Center.&nbsp;
FabCon + SQLCon bring together the full Microsoft data ecosystem covering everything data engineering, integration, warehousing, and real-time intelligence to AI-driven applications, advanced analytics, governance, and modern database development. The call for content is now open!
Submission guidance&nbsp;
The following FabCon and SQLCon track definitions outline the topics and session content Microsoft is seeking during the selection process. Prospective speakers can use this guide to identify the track that best aligns with their proposed session and to tailor submissions to the audience, technologies, and scenarios covered by that track. The number of sessions selected for each topic is guided by a preset allocation that creates a balanced conference program.&nbsp;
Submissions are evaluated through a blind review by members of the community, who can see the session title and details but not the speaker’s identity or other speaker information. Speakers should therefore ensure that the title and description clearly communicate the session’s focus, audience, technical depth, and expected takeaways. This guide is designed to help prospective speakers identify the track that best fits their session and understand the types of content track leads, reviewers and attendees expect within each area.&nbsp;
Need help choosing a track? Select the track that best matches the primary technology, audience, and learning objectives of your session.
Track definitions &nbsp;
Microsoft Foundry: The latest advancements in Azure AI, including machine learning models, AI-driven applications, and tools for building intelligent solutions. Sessions might cover topics like AI ethics, responsible AI, and practical implementations of Azure AI services.&nbsp;
Power Platform: Focusing on the Power Platform suite, including Power Apps, Power Automate, and Power Virtual Agents. Content covers building custom applications, automating workflows, and leveraging data insights.
Power BI: Specifically dedicated to Power BI, this track includes sessions on Power BI, Power Query, writeback, semantic models, visuals, reports, translytical task flows, DAX, data modeling and advanced analytics. Attendees might learn how to turn data into actionable insights.&nbsp;
OneLake: Focusing on OneLake, Microsoft's data lake solution. Content covers data storage, data processing, security features, Databricks unity catalog mirrored item, OneLake security, iceberg virtualization and integration with other Azure services for big data analytics.&nbsp;
Fabric Platform: Admin &amp; Governance: Focusing on the administrative and governance aspects of the Fabric Platform. Content might include Data governance, data protection, data management, administration, OneLake catalog, managing user access, ensuring compliance, and best practices for platform governance.&nbsp;
Fabric Platform: Dev Experiences: Incorporates the developer experiences within the Fabric Platform. Sessions might cover development tools, APIs, CI/CD, GitHub, Azure DevOps, Deployment Pipelines, Extensibility Toolkit, Automation, Capacities, Monitoring Hub, Metrics App, Workspace monitoring and building custom solutions on the Fabric Platform.&nbsp;
DE&amp;I: This track will focus on Diversity, Equity, and Inclusion (DE&amp;I) within the tech industry. Topics might include creating inclusive environments, promoting diversity in tech, strategies for equitable practices, and inclusive design.&nbsp;
Fabric Data Warehousing: This track covers the design, implementation, and management of modern data warehouses. Content might include data warehousing architectures, ETL processes, SQL endpoint, Metadata Sync (MDSync) and optimizing data storage.&nbsp;
Data Science in Fabric: This track covers Data Science in Fabric, including Multimodal and Generative AI in Fabric, Fabric Data Agents, machine learning, statistical analysis, and predictive modeling. Sessions cover tools, techniques, and real-world applications of data science.&nbsp;
AI &amp; Data Agents: This track focuses on conversational analytics with Microsoft Fabric Data Agents. Sessions might cover natural-language access to governed data across Fabric sources, agent configuration and semantic grounding, integrations with Microsoft Foundry, Copilot Studio, Microsoft 365 Copilot, Power BI, and custom apps, plus security, governance, responsible AI, and reliability.
Data Integration: This track focuses on integrating data from various sources and data movement. Topics include Data Factory, Power Query, Dataflow gen2, mirroring, ETL, pipelines, gateways, data migration, data transformation, and ensuring data consistency across systems.&nbsp;
Data Engineering in Fabric: This track highlights the role of data engineers in building and maintaining data infrastructure. Content includes lakehouse architecture, materialized lake views, data pipeline design, Apache Spark and notebooks using Python (PySpark), Scala, or SQL to process big data, environments, Spark Job Definitions, data quality management, and data engineering as it relates to Microsoft Fabric.&nbsp;
Databases in Fabric: A broader track that encompasses Operational Databases in the Microsoft product stack. Sessions might explore SQL databases in Fabric, Cosmos DB in Fabric, database architecture, data modeling, migration, and integration of other databases with Microsoft Fabric.&nbsp;
Cosmos DB: The capabilities of Cosmos DB include Cosmos DB in Fabric, Multi-Agent AI Apps, best practices for database management, scalability, performance optimization, and real-world use cases.&nbsp;
SQL Server &amp; Azure SQL: Covering various aspects of SQL databases in the cloud and on-prem, including design, development, and administration. Topics include administration, query optimization, database security, migration, and integration.&nbsp;
Real-Time Intelligence: This track explores real-time data processing and analytics. Sessions might include Real-Time Intelligence in Fabric, Event Streams, Activator, real-time dashboards, Digital twins solutions, Map, Graph, event driven architectures, event house, event stream, real-time hub, activator and use cases for industries that require immediate data insights.&nbsp;
Fabric IQ: This track highlights unified intelligent capabilities across Microsoft Fabric that accelerate insights and productivity. Sessions explore Ontology &amp; Semantic Modeling, Graph in Microsoft Fabric, Fabric Data &amp; Operation Agents, and integration with Foundry IQ.&nbsp;
Fabric Apps / Rayfin: This track focuses on building secure, governed, data-driven applications on Microsoft Fabric with Fabric Apps and the Rayfin SDK and CLI. Sessions might cover AI-assisted TypeScript development, generated database schemas and GraphQL APIs, authentication, hosting, deployment, OneLake integration, permissions, analytics, and AI.&nbsp;
Fabric Planning: This track focuses on enterprise planning with Plan in Microsoft Fabric. Sessions might cover budgeting, forecasting, scenario modeling, multidimensional allocations, collaboration and approvals, variance analysis, writeback to Fabric SQL databases, and aligning plans, forecasts, and actuals through governed semantic models.&nbsp;
