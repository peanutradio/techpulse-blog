title: Get tenant-wide visibility into workspace networking policies with the Admin
  API (Generally Available)
---

As organizations strengthen their security posture and adopt network security controls across their data platforms, visibility becomes just as important as enforcement.&nbsp;List Networking Communication Policies API, now generally available, provides Fabric Tenant administrators with a centralized, tenant-wide view of workspace networking policies configured for workspaces, making it easier to monitor configurations, support governance initiatives, and streamline security reviews.&nbsp;Why this mattersAs enterprises deploy controls such as Inbound Access Protection and Outbound Access Protection, administrators need a scalable way to monitor compliance, audit workspace configurations, and identify workspaces that may require additional review. Prior to this capability, administrators often relied on workspace-by-workspace inspection to understand networking settings.With this API, administrators can retrieve workspace networking communication-policy information through a tenant-level endpoint instead of reviewing workspaces individually. This helps organizations reduce manual review effort and gain more consistent visibility into networking controls across their Fabric estate. The response can be incorporated into governance reports, security-monitoring solutions, and compliance-review workflows.What the API provides&nbsp;The List networking communication policies Admin API returns workspace-level networking policy information for the tenant. Depending on the policies configured for a workspace, the response can include:&nbsp;Inbound communication policies&nbsp;Administrators can review configuration related to inbound access controls, including:&nbsp;Public access rule settings&nbsp;IP&nbsp;firewall&nbsp;rule configurations&nbsp;Default access behavior for inbound communication&nbsp;Outbound communication policies&nbsp;The API also exposes outbound communication controls, enabling visibility into:&nbsp;Public access restrictions&nbsp;Connection rules&nbsp;Gateway rules&nbsp;Git-related communication policies&nbsp;Managed Private Endpoint configurations&nbsp;Key benefits&nbsp;Centralized Governance:&nbsp;Gain tenant-wide visibility into networking configurations without manually inspecting individual workspaces.Security Auditing:&nbsp;Identify workspaces with restrictive or permissive network configurations and support internal security reviews.Compliance Monitoring:&nbsp;Validate that networking controls are configured according to organizational standards and regulatory requirements.Automation &amp; Reporting:&nbsp;Integrate networking policy data into existing governance dashboards, monitoring systems, SIEM solutions, and compliance reporting processes.&nbsp;Common scenarios&nbsp;Organizations can use this API to:&nbsp;Inventory all workspaces configured with inbound access restrictions.&nbsp;Identify&nbsp;workspaces using outbound access protection controls.&nbsp;Build security and governance dashboards for Fabric networking policies.&nbsp;Audit networking configurations during security reviews.&nbsp;Monitor&nbsp;the adoption&nbsp;of network security capabilities across the tenant.&nbsp;Automate compliance reporting for internal and external audits.&nbsp;Built for enterprise scale&nbsp;The API returns paginated results. When the response includes a continuation token, use that token to request the next page and continue until all available pages have been retrieved.&nbsp;The API supports filters for selected inbound and outbound policy conditions. Use the supported filter expressions to limit the response to workspaces matching those conditions.&nbsp;Who can use itThe API can be called by a Fabric administrator or by a service principal that is authorized to use read-only admin APIs. The calling application must use a supported tenant-level permission, such as Tenant.Read.All or Tenant.ReadWrite.All, as documented in the API reference.&nbsp;Getting started&nbsp;Security and governance teams can start using the List Networking Communication Policies Admin API to build a comprehensive view of networking controls deployed across their Fabric environment.&nbsp;Whether you're implementing Outbound Access Protection, monitoring network security posture, or building compliance automation, this API provides the visibility required to operate Fabric securely at enterprise scale.&nbsp;We’re&nbsp;excited to continue expanding the governance and security capabilities of Microsoft Fabric and helping organizations manage their data platforms with confidence.&nbsp;To get started, review the Security in Microsoft Fabricand&nbsp;Workspaces - List Networking Communication Policies - REST API (Admin)&nbsp;documentation and begin incorporating networking policy data into your existing governance, monitoring, and compliance workflows.&nbsp;Your feedback is essential! Let us know how we can make Fabric even more secure and flexible for your workloads by sharing your feedback at&nbsp;Fabric Ideas – Microsoft Fabric Community.&nbsp;
